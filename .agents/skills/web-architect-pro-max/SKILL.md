Inspired by top Claude Code design skills (`frontend-design`, `tasteskill-anti-slop`, `ui-ux-pro-max`, `design-lang-tastemaker`), **Web Architect Pro Max** enforces human-caliber art direction, radical domain-adaptive layout structures, and physically authentic 3D spatial computing.

## 1. The Pre-Flight Design Blueprint (Mandatory Before Coding)

Before writing any HTML, CSS, or JS, the agent must formulate this 4-step architectural blueprint:

1. **Industry Archetype & Emotional Tone**:
   - Deconstruct the user prompt into its true physical and emotional context.
   - *Is this high-intensity kinetic athletic conditioning? Haute Swiss horlogerie? DevSecOps tactical cyber defense? Precision genomic CRISPR analysis?*
2. **Visual Rhythm & Layout Density**:
   - Choose the structural layout pattern matching the domain:
     - **High-Density Telemetry Matrix** (Aerospace, Cybersecurity, Quantitative Finance): Compact grids, monospace telemetry values, live ticker strips, tactical HUDs.
     - **Spacious Editorial Lookbook** (Luxury Horlogerie, Architecture, Specialty Culinary): Generous whitespace, serif typography, high-contrast imagery, delicate hairline borders.
     - **Kinetic Skewed Arena** (CrossFit, Athletics, Racing): Bold geometric angles, dynamic contrast, high-cadence animation, interactive calculators.
     - **Modular Hardware Console** (Music Synthesis, Audio Engineering): Brushed metallic faceplates, interactive knobs, patch cables, real-time Web Audio oscilloscopes.
3. **Contrast Science & Typographic Pairing**:
   - Never default to generic Arial or flat `#333` grays.
   - Curate expressive Google Fonts with strict primary/secondary pairings.
   - Enforce WCAG AAA contrast ($\ge 7:1$) on deep atmospheric backgrounds with luminous undertones.
4. **Interactive Component Architecture**:
   - Every site must feature at least one **domain-native computational tool** (e.g. 1RM Barbell Calculator, Pour-Over Brew Ratio Dial, CVE Threat Simulator, Compound Yield Slider, ADSR Audio Keyboard, Orbital Delta-V Planner).

## 4. Stereoscopic 3D CSS Tilt Physics

Every card element must react dynamically to the cursor:
```javascript
card.addEventListener('mousemove', (e) => {
  const rect = card.getBoundingClientRect();
  const x = e.clientX - rect.left;
  const y = e.clientY - rect.top;
  const rotateX = ((y - rect.height / 2) / (rect.height / 2)) * -10;
  const rotateY = ((x - rect.width / 2) / (rect.width / 2)) * 10;
  card.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg) translateZ(10px)`;
  card.style.setProperty('--mouse-x', `${(x / rect.width) * 100}%`);
  card.style.setProperty('--mouse-y', `${(y / rect.height) * 100}%`);
});
```
